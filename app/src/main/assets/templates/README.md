# 出厂模板槽位（C 阶段机制，内容待放入）

本目录是"出厂模板"的安装源：`manifest.json` 的 `zips` 数组列出随包出厂的
模板 zip 文件名，应用在首个"从头制作游戏"回合会幂等安装它们（导入为新游戏
并自动置模板标记），与玩家在首页菜单甄选的模板汇入同一个参照库。

放入方式：

1. 在应用里把高质量游戏"导出zip"，得到一个 `ww_game.json` + 游戏文件的包；
2. 把 zip 改名后放入本目录（如 `sandbox-voxel.zip`）；
3. 在 `manifest.json` 的 `zips` 数组里登记该文件名；
4. 安装是幂等的（登记表 `agent/factory_templates.json` 记录已装条目），模板
   更新只需换 zip 并改一个新文件名。

注意：出厂模板应交付版号 ≥1 且验收全绿（导出前先确认可玩）；残缺包会被
导入校验拒绝并跳过（记 Log），不会阻塞生成回合。
